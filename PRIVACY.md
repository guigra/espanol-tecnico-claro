# Política de privacidad

**Proyecto:** Español técnico claro (`espanol-tecnico-claro`)
**Responsable:** Ricardo Guillén Gracia
**Última actualización:** 16 de noviembre de 2026

## Resumen

Este plugin no recoge, guarda ni envía datos.

## Qué contiene el plugin

El plugin contiene solo instrucciones de redacción en un archivo `SKILL.md`, metadatos y un icono. No incluye:

- conectores ni servidores MCP;
- hooks, scripts ni código ejecutable;
- llamadas de red a servicios propios o de terceros;
- almacenamiento, registros ni analítica.

## Tratamiento de datos

- **Lectura:** el plugin no lee datos de ninguna fuente. Claude aplica las instrucciones al texto que el usuario aporta en la conversación.
- **Almacenamiento:** el plugin no guarda datos. El autor no opera ningún servicio que reciba datos de los usuarios.
- **Envío:** el plugin no envía datos fuera de la plataforma. Los enlaces de la sección de referencias de `SKILL.md` son fuentes de consulta; el plugin no se conecta a ellas.
- **Conservación:** no aplica, porque el autor no recibe datos.

El tratamiento de las conversaciones depende de la aplicación que use el usuario, por ejemplo Claude, y se rige por la política de privacidad de su proveedor.

## Menores

El plugin está diseñado para redacción técnica profesional y no se dirige a menores de 18 años.

## Contacto

Para preguntas sobre esta política, abre una incidencia en <https://github.com/guigra/espanol-tecnico-claro/issues>.

# Privacy Policy (English)

This plugin does not collect, store, or transmit any data. It contains only writing instructions (a single `SKILL.md`), metadata, and an icon. It has no connectors, MCP servers, hooks, scripts, executable code, network calls, storage, logging, or analytics. All processing happens within the user's Claude conversation and is governed by the AI provider's own privacy policy. The author operates no service that receives user data. The plugin is intended for professional technical writing and is not directed at users under 18.
